# Triiibo Monorepo

Esse repositório é um monorepo que conterá o frontend e o backend, tal qual a documentação e quaisquer outros dados relacionados ao projeto.

## Estrutura

```
triiibo-monorepo/
├── frontend/
├── backend/
├── docs/
├── infrastructure/
└── README.md
```

## Setup

1.  **Install dependencies**

    ```bash
        npm install
    ```

2.  **Run the frontend**
    ```bash
        npm run dev
    ```
